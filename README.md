# Projeto Digital Store - Front-end

Projeto final desenvolvido durante o curso de Front-end da Digital College.

Aluno: Valmir Patricio de Medeiros  


## Sobre o projeto
O projeto consiste na criação da loja virtual Drip Store usando React e React Router. O layout foi baseado no Figma disponibilizado e nos requisitos pedidos pelo professor.

Foram feitas as 3 páginas principais:
- Home: carrossel de fotos, coleções em destaque, ícones de categorias, produtos em alta e banner de oferta especial.
- Listagem de Produtos: vitrine de calçados com filtros na lateral (marca, categoria, gênero e estado) e campo para ordenar.
- **Visualização do Produto:** tela com detalhes do tênis, galeria com miniaturas, opções de tamanho e cor, avaliações e botão de comprar.

## Tecnologias utilizadas
- React
- React Router DOM
- Vite
- CSS

## Como rodar o projeto

1. Instalar as dependências:
```bash
npm install
```

2. Executar em modo de desenvolvimento:
```bash
npm run dev
```

Abra no navegador o link gerado pelo terminal (http://localhost:5173).
